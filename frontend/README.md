# 🚀 JobFinder Pro - Frontend

This is the Next.js frontend directory for JobFinder Pro. 

For the complete project overview, setup guides, API endpoints, and system architecture, please refer to the master [Root README.md](../README.md).

## Quick Start (Frontend)

1. Make sure the backend is running or configured in your environment.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000) to view the application.
